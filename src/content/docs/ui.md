# UI (Zero-Bundle Components)

CSS-only interactive components. 0.0KB JavaScript shipped.

## Usage (modo correcto)
Import CSS/classes in global or page <style>; use semantic classes in your .nx templates. No <script> or islands needed for basic interactivity (pure CSS).

See package for available components (accordions, tabs, modals, etc. via classes + attributes).

Perfect complement to islands for cases where you want *no* JS at all.
