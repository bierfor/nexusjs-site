# Framework Comparison

How Nexus compares to mainstream full-stack frameworks.

| Feature | Nexus | Next.js | SvelteKit | Nuxt |
|---------|-------|---------|-----------|------|
| Islands architecture | ✅ Native | ❌ No | ⚠️ Partial | ❌ No |
| Runes reactivity | ✅ Native | ❌ No | ✅ Native | ❌ No |
| Server Actions | ✅ Native | ✅ Yes | ✅ Form actions | ✅ Yes |
| Zero JS by default | ✅ Yes | ❌ No | ⚠️ Partial | ❌ No |
| Built-in security audit | ✅ Yes | ❌ No | ❌ No | ❌ No |
| Hardened Mode | ✅ Yes | ❌ No | ❌ No | ❌ No |
| Multi-tenant routing | ✅ Native | ❌ No | ❌ No | ❌ No |
| Type-safe routing | ✅ Yes | ⚠️ Partial | ✅ Yes | ⚠️ Partial |
| SPA navigation | ✅ Morphing | ✅ Router | ✅ Router | ✅ Router |

Nexus is not a replacement for every app. It is the right choice when you want **surgical JS**, **security by default**, and **multi-tenancy** without glue code.
