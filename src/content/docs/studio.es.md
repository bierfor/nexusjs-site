# Nexus Studio

Un dashboard de desarrollo en tiempo real con cero dependencias externas.

## Lanzar

```bash
nexus studio
```

## Características

- **Inspector de rutas** — ve todas las rutas registradas, layouts y params
- **Log de requests** — log HTTP en tiempo real con filtrado
- **Tracker de islands** — qué islands se hidrataron, cuándo, y cuánto JS enviaron
- **Analizador de builds** — tamaños de bundles, grafo de chunks, reporte de treeshaking
- **Panel de seguridad** — violaciones CSP, resultados de audit, escaneo de fuga de secretos

## Cero deps

Studio está integrado en el CLI. Sin npm install, sin config, sin servicios externos.
