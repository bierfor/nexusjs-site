# Types (Seguridad End-to-End)

Genera automáticamente `nexus-types.d.ts` para seguridad de tipos completa a través de server/client (pretext, actions, etc.).

## Uso

Ejecuta vía CLI o plugin Vite durante dev/build. Importa tipos en tus .ts/.nx para `pretext` y resultados de actions.

Ver vite-plugin-nexus para integración.
