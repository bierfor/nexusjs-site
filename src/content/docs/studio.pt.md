# Nexus Studio

Um dashboard de desenvolvimento em tempo real com zero dependências externas.

## Lançar

```bash
nexus studio
```

## Recursos

- **Inspetor de rotas** — veja todas as rotas registradas, layouts e params
- **Log de requests** — log HTTP em tempo real com filtragem
- **Rastreador de islands** — quais islands hidratadas, quando, e quanto JS enviaram
- **Analisador de builds** — tamanhos de bundles, grafo de chunks, relatório de treeshaking
- **Painel de segurança** — violações CSP, resultados de audit, scan de vazamento de segredos

## Zero deps

Studio é integrado no CLI. Sem npm install, sem config, sem serviços externos.
