# Serialize (Transporte de Tipos Ricos)

Serialização lossless para tipos não-JSON entre servidor (pretext/actions) e cliente ($pretext / islands).

## Automático

O transporte do Nexus lida com Date, Map, Set, BigInt, RegExp, URL out of the box.

Sem código extra em load() ou actions.

Veja types para tipagem end-to-end.
