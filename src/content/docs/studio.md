# Nexus Studio

A real-time developer dashboard with zero external dependencies.

## Launch

```bash
nexus studio
```

## Features

- **Route inspector** — see all registered routes, layouts, and params
- **Request log** — real-time HTTP log with filtering
- **Island tracker** — which islands hydrated, when, and how much JS they shipped
- **Build analyzer** — bundle sizes, chunk graph, treeshaking report
- **Security panel** — CSP violations, audit results, secret leak scan

## Zero deps

Studio is built into the CLI. No npm install, no config, no external services.
