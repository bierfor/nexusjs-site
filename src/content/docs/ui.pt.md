# UI (Componentes Zero-Bundle)

Componentes interativos apenas CSS. 0.0KB de JavaScript enviados.

## Uso (modo correto)

Importe CSS/classes no global ou <style> da página; use classes semânticas em seus templates .nx. Não precisa de <script> ou islands para interatividade básica (CSS puro).

Veja o pacote para componentes disponíveis (accordions, tabs, modals, etc. via classes + atributos).

Complemento perfeito para islands em casos onde você quer *zero* JS.
