# UI (Componentes Zero-Bundle)

Componentes interactivos solo CSS. 0.0KB de JavaScript enviados.

## Uso (modo correcto)

Importa CSS/clases en global o <style> de página; usa clases semánticas en tus templates .nx. No se necesita <script> o islands para interactividad básica (CSS puro).

Ver el paquete para componentes disponibles (accordions, tabs, modals, etc. vía clases + atributos).

Complemento perfecto a islands para casos donde quieres *cero* JS.
