# Types (Segurança End-to-End)

Gera automaticamente `nexus-types.d.ts` para segurança de tipos completa através de server/client (pretext, actions, etc.).

## Uso

Execute via CLI ou plugin Vite durante dev/build. Importe tipos em seus .ts/.nx para `pretext` e resultados de actions.

Veja vite-plugin-nexus para integração.
